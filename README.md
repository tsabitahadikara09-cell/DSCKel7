# Dataset placement

Place your ISIC 2018 images in `dataset/images/` and the matching
`ISIC2018_Task3_Training_GroundTruth.csv` in this folder.

Example:
- dataset/images/ISIC_0000000.jpg
- dataset/ISIC2018_Task3_Training_GroundTruth.csv

Do not commit the full dataset to GitHub if it is large or restricted by its terms.
For Streamlit Cloud, the dataset must be available to the deployed server through
the repository, an external storage, or another server-accessible storage path.
